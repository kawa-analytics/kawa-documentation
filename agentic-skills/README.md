# Agentic skills

An agentic skill is a small folder you give to your AI assistant (Claude Code, Cursor, Codex, Copilot and the like) so that it knows how to do one KAWA task well. The folder holds instructions written for the assistant and the files it needs.

You download the folder, put it where you work with your assistant, and ask in plain language. There is nothing to install and nothing to configure.

Available skills:

* [Build a dashboard with your AI assistant](build-a-dashboard-with-your-ai-assistant.md) — a dashboard with figures, charts, filters and tables on top of a sheet, uploaded into KAWA as an artifact.
