# Riyu

Release notes of Riyu, KAWA's AI co-builder. See [Riyu — AI co-builder](../riyu-ai-co-builder.md).

Riyu is delivered as one image. Each version is named after the tag of that image. The versions are listed newest first.

## 2.5.8-3733

**Release date:** 27 November 2026

**New**

* **Files** — Word, Excel and PowerPoint files (`.docx`, `.xlsx`, `.pptx`) are previewed in the file browser, with zoom, and with sheet tabs for a workbook.
* **Design** — a theme can be created and edited on the Design page: from scratch, from the address of a website, or as a copy of a built-in theme. It holds the brand's colours, fonts, logos and images, in Light and Dark, with a live preview.
* **Design** — the active theme is applied to the HTML applications that Riyu generates.
* **Chat** — a message sent during a run is either queued or steers the run at its next step; the Send button chooses which. A message not delivered when a run is stopped shows as **Not sent**, with a **Send** action.
* **Errors** — an action that fails is reported in an error toast.

**Fixes**

* **Files** — long lines wrap in a file preview, and a PDF scrolls continuously.
